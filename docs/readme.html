Modeling and Inference

Three projects on what measurements reveal about biological models, gene networks and image representations.

Explore the visual portfolio → · Studies and methods

Study Method and recorded result Inspect
Biological mechanisms ODE simulation and parameter refitting. Three input pulses improve correct selection from 61–83 to 99–100 of 100 trials, with equal duration, observations, total input and noise scale. Study · Counts and trajectories
Gene-network recovery SVD removal of shared activity and directed-edge ranking. At one simulated setting, normalized average precision rises from 0.24 to 0.63. The full grid records the dependence on signal and noise. Study · Simulation grid
Image representations Within-class PCA/ICA and fitted latent transforms. A brightness rule transfers to 96 new configurations and six multipliers, across three trained encoders. Study · Transfer measurements

Approach and context

The projects use Python, SciPy and PyTorch. Each study includes interactive figures, saved measurements and scripts for rebuilding its plots.

The biological models come from Ryzowicz & Yildirim (2023). The network study connects to BEELINE and modular response analysis; the representation study connects to learning from paired changes.

The pulse and recovery-map results are simulations. Separate comparisons cover five DREAM4 networks, eighteen BoolODE datasets and real-cell response consistency. Image tests distinguish exploratory attribute discovery from held-out transform evaluation. Each study states its assumptions and baselines beside the result.

Reproduce the presentation

python -m pip install -r requirements.txt
python scripts/generate.py
python scripts/build.py
python scripts/check.py
python -m http.server 4181 --bind 127.0.0.1 --directory dist

Python 3.11+ and Node.js 18+ are required. These commands regenerate the figures and site from included measurements. Original model training and full fitting runs are maintained in the source projects; provenance identifies what is included. The checker validates local links and the SHA-256 data manifest.
