Does preprocessing change which method ranks first?

Each simulated dataset includes gene-expression measurements and the network that generated them. A linear model ranks possible connections by the size of its fitted coefficients.

In raw units, the model trailed the leading comparison method on both benchmarks. Centering and scaling each gene put it ahead on both, using the same observations and reference edges.

Reading the same observation pairs backward sharply reduced the standardized model’s score on DREAM4. On BoolODE, its score changed little.

When does removing variation help classify a digit?

If training images of some digits are blurrier than others, blur can become a shortcut. What happens when the blur in the test images is independent of the digit label?
